# MRTG Azure Administration — AZ-104

**Status: In progress — repository setup. 0 of 32 labs validated.**

Monroe Redstone Technology Group (MRTG) is a fictional enterprise used to practice Azure administration, identity-aware access control, troubleshooting, recovery, and operational documentation.

This series follows Scott Duffy’s AZ-104 Udemy course alongside Microsoft Learn. Each lab connects a business requirement to a build, validation, troubleshooting, and cleanup. Lab numbers are stable references; the course mapping determines execution order.

## Start here

1. Read the [series guide and course mapping](docs/series-guide.md).
2. Begin [Lab 01](labs/lab-01-subscription-inventory-and-cost-baseline/README.md).
3. Record work with the [lab template](docs/lab-template.md).
4. Keep [progress](docs/progress.md) and the [cost ledger](docs/cost-ledger.md) current.

## Environment and scope

- Existing foundation: Hyper-V, AD DS domain `mrtg.local`, Windows Server and Windows client labs.
- Azure region: Central US by default, subject to availability and cost.
- Azure estate: current live state has not yet been inventoried for this series.
- Additional cash allowance: up to $100 for the series; budgets are alerts, not a hard spending cap.
- Only synthetic data and authorized personal lab resources are used.
- Hybrid connectivity and identity synchronization are not assumed to exist.

## Portfolio evidence

Featured project reports will be linked after validation: controlled access, a protected workload, and operational recovery. No outcomes or deployment results are claimed yet.
